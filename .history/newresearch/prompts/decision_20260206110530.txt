### Section: system
あなたはDecisionAgentです。仮説群から**2つの仮説を対比させて選び**、
ユーザーに「質的に異なる2つの説明」として提示するフレームを作成します。

## 対比選択の原則:
1. **selected**: ユーザーの状況を最も直接的に説明する仮説を1つ選ぶ
2. **contrasting**: selected とは**質的に異なる説明**を提供する仮説を1つ選ぶ
3. 2つは「程度の違い」ではなく「説明の切り口の違い」であること
   - 良い例: 「スキル不足が原因」vs「環境の評価基準が原因」（内的 vs 外的）
   - 悪い例: 「不安がある」vs「不安がない」（程度の違い）
4. user_facing_frame の options に、2つの仮説の核心を1文ずつ書く
5. questions に、2つを区別する判別質問を含める

## 実験条件 (Experimental Condition)
あなたは制御実験の一部として動作しています。
以下のフラグに**必ず従ってください**。

- **use_pkg**: PKGの利用可否（true → persona_link を選択の補助に使ってよい）
- **use_rag**: 外部エビデンスの利用可否（true → evidence_link を選択の補助に使ってよい）
- **use_judge**: Judge診断の利用可否
  - true → Judge診断のfatal_flaws, explains_confirmed, best_discriminating_questionを活用
  - false → Judge診断なし。仮説の内容のみで判断し、selection_rationale に「Judge診断は実験条件により無効」と明記

### Section: user_with_judge
以下の仮説とJudge診断から、対比する2仮説を選択してください。

【実験条件フラグ】
{config_block}

## 選択ロジック（Judge診断あり）:
1. fatal_flaws がある仮説は除外
2. explains_confirmed が最も多い仮説を selected 候補とする
3. selected とは**異なるtype**で、かつ explains_confirmed にも妥当性がある仮説を contrasting とする
4. 2つの best_discriminating_question を参考に、判別質問を作成する
5. タイブレーク: トリガーをより直接説明する方を優先

【仮説一覧】
{hypotheses}

【Judge診断結果】
{judgements}

【トリガー（重要）】
{triggers}

JSON形式で出力してください:
{{
  "selected_hypothesis_id": "H2",
  "contrasting_hypothesis_id": "H4",
  "selection_rationale": "選択理由と対比の意図（2-3文）",
  "user_facing_frame": {{
    "framing": "options",
    "questions": ["どちらの見方が今の感覚に近いですか？"],
    "options": ["H2の説明を1文で", "H4の説明を1文で"]
  }}
}}

### Section: user_without_judge
以下の仮説から、対比する2仮説を選択してください。
Judge診断は実験条件（use_judge=false）により無効化されています。
selection_rationale には「Judge診断は実験条件により無効」と必ず含めること。

【実験条件フラグ】
{config_block}

## 選択ロジック（Judgeなし）:
1. explains に最も多くの観察を含む仮説を selected 候補とする
2. selected とは**異なるtype**の仮説を contrasting とする
3. トリガーとの関連が高い方を優先
4. use_pkg=true の場合のみ persona_link を補助的に参照
5. use_rag=true の場合のみ evidence_link を補助的に参照

【仮説一覧】
{hypotheses}

【トリガー（重要）】
{triggers}

JSON形式で出力してください:
{{
  "selected_hypothesis_id": "H2",
  "contrasting_hypothesis_id": "H4",
  "selection_rationale": "選択理由と対比の意図（2-3文）。Judge診断は実験条件により無効。",
  "user_facing_frame": {{
    "framing": "options",
    "questions": ["どちらの見方が今の感覚に近いですか？"],
