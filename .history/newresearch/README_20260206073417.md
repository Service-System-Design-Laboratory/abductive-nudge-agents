# Abductive Dialogue Pipeline — Extended Paper Experiment

> **Empathy-Driven Abductive Reasoning in Multi-Agent Dialogue Systems**
>
> This module implements a reproducible experiment for observing how abductive
> reasoning processes (Trigger → Hypothesis → Evaluation → Selection) contribute
> to empathetic and creative dialogue, with internal ablation across three
> knowledge-source dimensions: **PKG**, **RAG**, and **Judge**.

---

## 1. Research Question

| # | Question |
|---|---------|
| RQ1 | How does the explicit abductive pipeline (Trigger → Hypothesis → Judge → Decision) shape the diversity and quality of generated hypotheses? |
| RQ2 | What roles do Personal Knowledge Graphs (PKG) and external evidence (RAG) play in hypothesis grounding and persona alignment? |
| RQ3 | Does agent-as-a-judge scoring improve the selection of empathetic, well-grounded responses? |

## 3. Pipeline Architecture

```
user_input + persona + PKG + config
        │
        ▼
┌──────────────┐
│ ContextAgent │  Trigger extraction + RAG query plan
└──────┬───────┘
       │  triggers, rag_queries
       ▼
┌──────────────┐
│ExplorerAgent │  External evidence via Serper API  [skip if use_rag=false]
└──────┬───────┘
       │  evidence_items
       ▼
┌────────────────┐
│HypothesisAgent │  3–5 diversified hypotheses  [PKG seeds diversity if use_pkg=true]
└──────┬─────────┘
       │  hypotheses[]
       ▼
┌────────────┐
│ JudgeAgent │  4-axis scoring per hypothesis  [skip if use_judge=false]
└──────┬─────┘
       │  judgements[]
       ▼
┌───────────────┐
│ DecisionAgent │  Select 1 hypothesis + rationale
└──────┬────────┘
       │  selected hypothesis + user_facing_frame
       ▼
┌────────────────┐
│ DialogueAgent  │  Empathetic response + nudge markers
└────────────────┘
       │
       ▼
   final_response + full JSON logs
```

## 9. Execution

```bash
# Run all 12 ablation experiments
python -m newresearch.runner --all

# Run a single condition
python -m newresearch.runner --scenario S1 --condition A

# Collect metrics → CSV
python -m newresearch.metrics

# Generate figures
python -m newresearch.visualize
```

### Execution Matrix

3 scenarios × 4 conditions = **12 runs** (minimum).
Optional: 2 repetitions per run (24 runs) for variance observation.

## 10. Fallback Handling

| Failure | Recovery |
|---------|----------|
| JSON parse error | 1× repair prompt retry |
| 0 evidence items | Continue; cap `evidence_reliability` at 3 |
| Too few hypotheses | 1× regeneration with explicit count constraint |
| Judge score bias | Fixed tie-break order (no manual override) |
